# Aelo Browser 0.1.0 — Developer Preview 1

The first prebuilt macOS developer preview. The app currently uses **Orbit** as its working name; the ZIP contains `Orbit.app`.

## Download and installation

- **Platform:** Apple Silicon Macs (M1 or newer), macOS 13 or later. The current development Mac was tested; macOS 13 itself was not.
- Download `Aelo-Browser-0.1.0-preview.1-macos-arm64.zip`, unzip it, and move `Orbit.app` to Applications.
- `SHA256SUMS.txt` contains the archive checksum.
- This is an **ad-hoc signed development build, without Apple Developer ID signing or notarization**. macOS Gatekeeper may block opening the downloaded app. A properly signed/notarized public distribution is still pending.

## Included

- Native macOS sidebar and real Chromium 156 browsing through CEF.
- Spaces with shared or separate persistent Profiles.
- Tabs, pins, tab renaming, command bar and two-pane Split View.
- Archive/restore, workspace export and restart restoration of saved URLs, pins and split membership.
- Cancelable unsaved-page confirmation before archiving a live tab.

## Validation

The native workspace tests passed. Live checks covered HTTPS browsing, cookie sharing between Spaces, cookie isolation between Profiles, split rendering, archive/restore, unsaved-page cancellation, orderly shutdown and restart recovery. The release archive was checked for ZIP integrity and recursive app signature validity.

## Known limits

- This is an early development preview, not full Arc feature parity or a qualified daily browser.
- Arc import, nested folders, Auto-Archive, Peek, Little Arc, routing, Boosts, Easels, sync and AI are not implemented.
- Chrome extension/Web Store compatibility, real account login flows, passkeys, DRM/media calls and the full browser-platform surface are not yet qualified.
- Tabs restore saved URLs, not complete back/forward history or unsaved form content. Split widths reset to equal sizes after restart.
- No automatic updates or public notarization yet. No Intel, Windows or Linux build is included.

The app uses its own `~/Library/Application Support/OrbitPreview/` directory. It does not import or modify Arc's browsing data. No personal browser profile is included in the download.
